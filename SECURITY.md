# Security Policy

Do not publish sensitive vulnerabilities in a public issue. Enable GitHub Private Vulnerability Reporting before the first public release.

Sensitive areas include OpenAI API key storage, Keychain access, accidental key logging, audio permissions, ScreenCaptureKit permissions, transcript leakage, crash-report contents, debug logging, and any future relay/backend service.

Never commit API keys, access tokens, private meeting recordings, or confidential transcripts.
