# Contributing

Contributions are welcome. SpeakAcross is currently an early MVP, so small, focused changes are preferred.

Current priorities:
1. reliable macOS audio capture
2. low-latency OpenAI realtime translation
3. separation of microphone and system-audio streams
4. stable original + translated subtitle rendering
5. secure BYOK handling through Keychain
6. privacy-preserving defaults

Run `swift build` and `swift test` before submitting changes.

Do not include API keys, private meeting recordings, or confidential transcripts in tests, fixtures, issues, or pull requests.
